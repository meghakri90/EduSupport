# AI Usage Report – EduSupport

## 1. Purpose of AI Usage

AI-assisted development was used during the development of EduSupport to improve development speed, explore implementation approaches, generate initial code structures, debug issues, and validate the overall product workflow.

AI-generated code was reviewed, tested, and modified before being used in the project.

## 7. Incorrect AI Output / Issue Identified

### API Port Mismatch

During development, an example API URL used port `7000`, while the actual ASP.NET Core project was configured to use port `7216` for HTTPS and `5293` for HTTP.

The issue was identified by checking the project's `launchSettings.json` and the actual running API URL.

The frontend/API configuration was then updated to use the correct development API port.

### React Port Conflict

The React development server initially used port `5173`, but that port was already in use.

Vite automatically started the frontend on port `5174`.

The CORS configuration in the backend was updated to allow the actual frontend origin.

### HTTPS Redirection During Local Development

The frontend was initially communicating with the HTTP API during local testing, while HTTPS redirection caused problems with the API requests.

For local development and testing, HTTPS redirection was temporarily disabled so that the frontend could communicate with:

`http://localhost:5293`

This was treated as a local development simplification rather than a production security configuration.
